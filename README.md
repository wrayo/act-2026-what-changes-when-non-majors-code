# ACT 2026: What Changes When Non-Majors Code

William Rayo, Assistant Professor of Teaching, Department of Psychology, UC Davis.

A 24-slide sharing edition of the presentation.

Contains data-workflow demonstration, animated word cloud, lab-rubric animation, and local tutorial GIF preview. The Kaltura tutorial video and external practice app require an internet connection.

This repository contains the static presentation and its required display assets. GitHub Pages publishes the repository root from the `main` branch. The `.nojekyll` file preserves the Quarto support folders.

The full editable presentation and research data are maintained separately.
